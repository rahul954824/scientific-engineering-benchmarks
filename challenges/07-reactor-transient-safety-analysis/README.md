# Reactor Transient Safety Analysis

**Domain:** Reactor physics  
**Type:** Conceptual challenge brief

## Scenario

A research team is studying a low-power reactor transient and needs to understand how control inputs and temperature feedback influence the response. The exercise uses synthetic, non-operational data.

## Agent task

Choose a suitable point-kinetics model, estimate selected feedback parameters, and analyze transient response over a clearly bounded educational scenario.

## Key reasoning challenges

- Handling coupled neutron-population and delayed-group dynamics.
- Understanding feedback signs, units and time scales.
- Treating detector noise and finite measurement intervals appropriately.
- Identifying where model assumptions cease to be reliable.

## Expected deliverables

A documented educational model, parameter estimates, bounded transient plots and a safety-oriented discussion of assumptions.

## Evaluation focus

Equation implementation, dimensional consistency, numerical stability and correct communication of limitations. This brief is not an operational reactor-control procedure.
