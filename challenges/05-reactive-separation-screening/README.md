# Reactive Separation Screening

**Domain:** Chemical engineering / thermodynamics  
**Type:** Conceptual challenge brief

## Scenario

A process team is screening whether a reaction and a downstream separation step can be integrated. Available batch and equilibrium observations may cover multiple composition regions.

## Agent task

Formulate a thermodynamic and reaction-equilibrium model, analyze plausible phase behavior, and assess whether candidate process configurations are feasible.

## Key reasoning challenges

- Distinguishing single-phase and multiphase equilibrium.
- Ensuring thermodynamic consistency across composition ranges.
- Detecting multiple stationary or limiting operating states.
- Avoiding conclusions based only on a coarse parameter or composition grid.

## Expected deliverables

Model assumptions, equilibrium calculations, phase-stability checks, a feasibility comparison and explicit caveats about the data range.

## Evaluation focus

Thermodynamic consistency, numerical root handling, phase interpretation and traceability of feasibility conclusions.
