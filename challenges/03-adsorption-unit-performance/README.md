# Adsorption Unit Performance

**Domain:** Separation processes  
**Type:** Conceptual challenge brief

## Scenario

A fixed-bed adsorption unit treats a changing feed mixture. The engineering team needs to predict outlet composition over time for different feed recipes and loading histories.

## Agent task

Select and implement an appropriate adsorption model, use laboratory or pilot observations to constrain its parameters, and predict breakthrough behavior for unseen operating cases.

## Key reasoning challenges

- Competitive adsorption and nonlinear equilibrium behavior.
- Propagation of a concentration front through a finite bed.
- Distinguishing equilibrium effects from transport limitations.
- Maintaining physically valid concentrations and component balances.

## Expected deliverables

A model rationale, parameter estimates, predicted outlet histories, balance checks and a discussion of when the chosen model is inadequate.

## Evaluation focus

Conservation, correct limiting behavior, robust numerical treatment and generalization to unseen feed conditions.
