# Bioprocess Throughput Planning

**Domain:** Bioprocess engineering  
**Type:** Conceptual challenge brief

## Scenario

A biological treatment or production vessel must operate across changing feed conditions. Batch observations and limited continuous-operation records are available.

## Agent task

Estimate a suitable growth or conversion model and determine a throughput range that satisfies a stated product-quality or effluent constraint.

## Key reasoning challenges

- Substrate inhibition and coupled resource limitations.
- Multiple possible steady operating states.
- Dynamic recovery following a feed disturbance.
- Distinguishing transient performance from steady-state capacity.

## Expected deliverables

A calibrated model, steady-state and dynamic predictions, a feasible throughput recommendation and a shock-response assessment.

## Evaluation focus

Mass-balance closure, correct dynamic behavior, steady-state analysis and sensitivity to uncertain biological parameters.
