# Freeze-Drying Cycle Planning

**Domain:** Pharmaceutical engineering  
**Type:** Conceptual challenge brief

## Scenario

A development team wants to compare primary-drying cycle settings using vial temperature and equipment measurements from pilot runs.

## Agent task

Construct a simplified coupled heat- and mass-transfer model and identify operating conditions that satisfy a product-temperature limit while meeting cycle-time and equipment constraints.

## Key reasoning challenges

- Distinguishing product temperature from shelf and sensor readings.
- Representing changing resistance as the dried layer grows.
- Accounting for vial-to-vial and measurement variability.
- Recognizing equipment limits that restrict otherwise attractive settings.

## Expected deliverables

A model description, parameter estimates, predicted temperature and drying trajectories, and a justified cycle-design comparison.

## Evaluation focus

Heat/mass balance consistency, correct constraint interpretation, sensitivity analysis and explicit model limitations.
