# Process Controller Tuning

**Domain:** Process control  
**Type:** Conceptual challenge brief

## Scenario

A process loop has a delayed response and may exhibit non-minimum-phase behavior. Historical input/output data are available from controlled tests.

## Agent task

Identify a low-order dynamic model and compare controller settings against tracking, disturbance-rejection and robustness criteria.

## Key reasoning challenges

- Estimating delay and dynamic response from sampled measurements.
- Recognizing inverse response and avoiding misleading simplified fits.
- Balancing speed of response against overshoot and robustness.
- Validating tuning on disturbances not used during identification.

## Expected deliverables

A model with fit diagnostics, candidate controller settings, simulated response comparisons and a recommended tuning rationale.

## Evaluation focus

Identification quality, stability checks, robustness, reproducibility and clarity of trade-offs.
