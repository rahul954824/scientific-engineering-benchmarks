# Synthesis Loop Operating Envelope

**Domain:** Reaction engineering  
**Type:** Conceptual challenge brief

## Scenario

An industrial synthesis loop has historian records across a narrow range of operating conditions. Engineers want to reconcile the measurements and understand how the system may behave at proposed setpoints.

## Agent task

Build a steady-state process model, estimate uncertain parameters from plant observations and map a defensible operating envelope for specified performance and equipment constraints.

## Key reasoning challenges

- Reconciling coupled reactor and heat-exchanger behavior.
- Handling inconsistent or biased plant measurements.
- Recognizing nonlinear solution branches and operating transitions.
- Avoiding unjustified extrapolation beyond the evidence.

## Expected deliverables

A model and fit diagnostics, predicted operating points, constraint checks and a clear statement of the envelope's validity.

## Evaluation focus

Mass and energy balance closure, parameter plausibility, nonlinear solution handling and disciplined extrapolation.
